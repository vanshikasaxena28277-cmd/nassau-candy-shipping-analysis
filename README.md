# Shipping Route Efficiency Analysis

## Overview
This project analyzes shipping efficiency for Nassau Candy Distributor.

## Files
- app.py → Streamlit dashboard
- Nassau Candy Distributor.csv → dataset
- analysis.ipynb → basic analysis
- research_paper.pdf → report
- requirements.txt → dependencies

## How to Run

1. Install libraries:
pip install -r requirements.txt

2. Run the app:
streamlit run app.py

## Features
- Lead time calculation
- Filters (Region, Ship Mode)
- Fastest & Slowest routes
